# Manipulating Data with Pandas 🐼

## About this project
This is my first data analysis project. Using a publicly available dataset from Kaggle, 
I practiced core data manipulation techniques with Python and Pandas in Google Colab.

---

## Dataset
**Raw:** [`surgery.csv`](surgery.csv) — original dataset from [Kaggle](https://www.kaggle.com/)

**Cleaned:** [`surgery_cleaned.csv`](cleaned_surgery.csv) — output after data cleaning

## What this notebook covers
- Extracting and filtering data
- Working with multiple filter conditions (`&`, `|`, `~`)
- Creating and updating new dataframes
- Renaming columns and data cleaning
- Creating categorical variables from numerical data
- Sorting values
- Handling missing values (deletion and imputation methods)
